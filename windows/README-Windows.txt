Rhine Music · Windows 私有增强版 · 2026-10-08

双击 Rhine Music.exe 打开独立播放器窗口。
无需安装 Node.js、Python、Unicorn、FFmpeg 或开发环境。
首次自动展开自带运行文件到本机应用数据目录，之后复用。
关闭窗口会停止本程序拥有的音频、处理进程和本地服务。

在「音乐库」添加完整音乐目录并扫描；设置内可连接 FTP / FTPS。
不改写歌曲或标签，不在远端执行写入／删除。SFTP 未支持。
曲库、缓存、FTP 凭据及偏好保存在本机用户数据目录，不随 EXE 分发。

默认原生 WASAPI；设置支持厂家 ASIO 驱动与输出声道。
接入设备并安装厂商 ASIO 驱动后，点击「停止播放并刷新设备」。
没有安装驱动时不会出现虚构的 ASIO 设备。

DSF 与未压缩 DFF 可转换为 PCM，或通过 ASIO 原生 DSD / DoP 直出。
DSF 的 ID3v2.3 / v2.4 中文标签、曲号／碟号及内嵌封面可读取。
原生 DSD 和 DoP 均锁定数字音量、旁路 Sony 音效和淡入淡出。
DoP 仍是 DSD；需要音效请选择 DSD 转 PCM。
已在接入的 FiiO ASIO 驱动上验证 192 kHz PCM、合成静音 DSD64
原生／DoP 的启播、暂停、跳转、停止；DSD128／256 仅查询支持。
DST 压缩 DFF、热拔插及长期稳定性未验证。

Sony 原版 DSEE AI、DCフェーズリニアライザー、バイナルプロセッサー
运行文件包含在本私有包中；首次处理生成本机缓存，之后复用。
三项音效在 x86 C++ 中执行，模型和参数保持原版；246 组原 ARM
对照的音频及内部状态逐位一致。相位器已修复左右共用历史的串扰。
设置提供多核、实时运算进度与透明标志，约半秒音频缓冲后播放。
点击顶部正在播放的歌名可打开专辑详情及技术标志。
播放时底部是 Liquid Glass 浮动胶囊：左侧切歌／暂停，中间封面、
歌名和进度，右侧音量与当前曲目入口；玻璃实时折射三维场景，
提供线性流光、按压反馈和居中的图标，适配暖昼／深夜和减少动态效果。
底部显示进度与已播／总时长；Pad 竖屏自动使用两行触摸布局。
Pad 拖动先预览、松手才跳转，原生 DSD／DoP 音量显示 DAC。
排序、扫描或页面刷新后接回同一原生会话，保留暂停及进度，
旧页面迟到的请求不会停止或重开已恢复的播放。
DSEE 原版接受 44.1／48 kHz；相位／黑胶支持 44.1、48、176.4、192 kHz。
高采样率逐项旁路不支持的效果，保留原采样率并显示说明。
24／192 ALAC 从原配置读取正确参数，旧索引自动升级。

Hi-Res 原音源显示金色 SVG 标志，整张专辑每首均符合时，
浏览与详情标题旁显示标志，玻璃盒左右边框镶同款金色。
标志带线性扫光；减少动态效果时静止。混合专辑逐曲标记，
FTP 下载后读取原音源参数，DSEE 升频不影响标记。
DSD 音源同时显示 Hi-Res 和 DSD；全 DSD 专辑有双标志及金边。
DSD SVG 透明背景，暖昼石墨色／深夜银白色，金色线性扫光；
转 PCM 播放仍保留原 DSD 标记，减少动态效果时静止。

封面图集常驻显存，变化时只上传局部，避免整张大图反复传输；
进场计时前预热三维渲染，桌面优先使用独立显卡。
渲染比例只控制内部画质，界面比例由实际窗口尺寸决定。

界面支持 Pad 横竖屏触摸，服务只监听 127.0.0.1；
不包含另一台 iPad 经局域网连接的部署方式。

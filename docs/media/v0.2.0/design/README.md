演示列只有两张“氛围音乐”封面和一张“器乐”封面，因此导航动图展示选中、分类及数量切换，没有冒充超过 12 张时的长滑尺滚动。

### 标题尺寸变化补录

内置演示专辑的名称都较短，因此为 `title-layout.gif` 单独生成两个 1 秒静音 FLAC 文件，分别写入“日光留声”和“在日光消失之前，沿着静默的海岸线继续远行，写给尚未到来的漫长夏天”作为示例专辑名，歌手统一标为“RHINE · 排版演示”。封面直接沿用 `public/demo-covers/square.png`，通过正式版扫描和切换专辑入口显示，没有替换页面文字或注入动画。

动图记录点击下一张、再点击上一张的完整过程，源片段约 6.1 秒、共 90 帧。短标题为单行，长标题自动适配成两行并缩小字号；裁切保留了歌手、年份和“打开专辑”入口，便于观察整个信息区域的展开与收拢。录制没有播放音频；示例标题不代表真实发行专辑，临时音频、索引和配置不随文档分发。

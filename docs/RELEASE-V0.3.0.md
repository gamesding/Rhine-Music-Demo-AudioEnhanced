# V0.3.0 发布检查

发布日期：2026-10-01。基于公开仓库 `RonaldDeng/Rhine-Music-Demo` 的 V0.2.0 后续文档提交整理，发布标签为 `v0.3.0`，面向 macOS。完整改动见 [CHANGELOG](../CHANGELOG.md)，界面记录见 [UI-REVIEW-V0.3.0](UI-REVIEW-V0.3.0.md)。

## 本次内容

- 横屏主页的名称区与取景调整，暖昼玻璃壳体可见度、标题下伸笔画及封面切换连续性修正。
- 顶部播放标题可定位当前歌曲；搜索与播放标题共用两次柔和高亮，不改变播放状态。
- Esc 返回控件统一恢复到左上品牌标识下方；移除顶部中文曲库统计，保留底部英文专辑／曲目统计。
- README、CHANGELOG、设计与历史文档统一版本命名；本次只发布 V0.3.0，不为 V0.0.1–V0.0.3 补发历史标签。
- 修正两处原有检查加载问题：`data.ts` 的音乐排序导入／重导出补充 `.ts` 扩展名；灯光检查脚本解析并转译共用主题过渡依赖。没有因此更改音乐排序或灯光行为。

## 实际执行的检查

环境：macOS、Node.js 26.3.0、npm 11.16.0。

- `npm ci --no-audit --no-fund`：锁定依赖安装成功，没有升级依赖版本。npm 提示 esbuild／fsevents 安装脚本未列入 allowScripts；未改变批准设置，生产构建仍正常完成。
- `npm run build`：内容导出、TypeScript、Vite 与 PWA 生成通过。最终 PWA 资源版本为 `1db6186ea4d118e9`，74 个文件，约 28.2 MiB。
- `npm run check:content`：18 项通过。
- `npm run check:viewport`：通过。
- `npm run check:music`：完整命令通过，包括曲库与专辑介绍 16 项、播放控制 4 项、展示流程 21 项，以及阵列循环、封面比例、运动、相机、灯光和玻璃模型检查。
- 发布改动经过独立源码复核。版本与锁文件一致，相关文档本地链接和 `git diff --check` 通过。
- Vite 保留已有的共享产物大于 500kB 提示，不属于构建失败。

## 打包与资料范围

下载文件为 `Rhine-Music-Demo-v0.3.0-macOS.zip`，解压顶层目录为 `V0.3.0/`。源码包由发布 Git 提交导出，保留启动器可执行权限、完整源码、锁文件、运行资源、模型源文件、文档及许可证。附件 `SHA256SUMS.txt` 提供 ZIP 的 SHA-256 校验值。

候选文件检查未检出常见凭据、真实本机个人路径或个人曲库数据；新增截图使用示例数据，不带 EXIF／XMP 元数据。Blender 源文件与已公开基线相同。保留上游作者署名、MIT 文本、Git 历史与第三方来源说明；本次不重写历史。

`.git`、`node_modules`、`dist`、个人音乐、封面缓存、曲库索引、配置、日志与本地备份均不纳入源码 ZIP。音乐文件继续从用户配置的原目录读取；数据目录仍为工程旁的 `music-data-v3`。
